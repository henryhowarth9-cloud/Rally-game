
Rally Web Game
==============
Drop-in React demo of a simple rally-style canvas driving game.

How to run locally:
1. unzip the project
2. cd rally-game
3. npm install
4. npm run dev
5. open http://localhost:5173

How to deploy quickly:
- Vercel: import this repo or drag & drop; default Vite settings work.
- Netlify: link repo and use `npm run build` with publish directory `dist`.
